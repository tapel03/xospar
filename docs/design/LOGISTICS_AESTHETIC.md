# Logistics-inspired UI refresh

This build applies the user-approved aesthetic while preserving the Edgeline feature set and navigation.

- Neutral off-white app canvas
- Clean white cards with subtle grey borders and low shadows
- High-contrast black hero cards and primary actions
- Rounded pill controls and compact typography
- Black active navigation states
- Restrained pale-blue status accents only where useful
- Existing trading, journal, mentor, alerts, strategy, analytics and market flows retained
